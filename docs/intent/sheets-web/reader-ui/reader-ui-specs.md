# Reader UI Specs (EARS)

- [x] SHEETS-READ-001: When a user selects a sheet, the system shall load and display its content.
- [x] SHEETS-READ-002: While a selected sheet format is markdown, the system shall render it as HTML for reading.
- [x] SHEETS-READ-003: While a selected sheet contains Hebrew text, the reading view shall preserve right-to-left readability.
- [x] SHEETS-READ-005: The Reader view shall present a compact header containing the sheet title and a Back affordance to the Discovery view, and shall omit discovery controls.
