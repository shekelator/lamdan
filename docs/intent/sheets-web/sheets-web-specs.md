# Sheets Web Specs (EARS)

- [x] SHEETS-WEB-001: When the application starts, it shall load the sheet catalog from static assets and present discoverable sheet entries.
- [x] SHEETS-WEB-002: While running on a mobile viewport, the application shall present a usable layout without horizontal overflow.
- [x] SHEETS-WEB-003: The application shall present discovery and reading as distinct, mutually exclusive views, each reachable by a stable URL.
- [x] SHEETS-WEB-004: The application shall render both Markdown and HTML sheet files selected from the catalog.
