# Catalog and Search Specs (EARS)

- [x] SHEETS-CAT-001: When a user enters search text, the system shall filter sheets by matches in title, summary, topics, or tags.
- [x] SHEETS-CAT-002: When a user selects a topic filter, the system shall show only sheets containing that topic.
- [x] SHEETS-CAT-003: When a user selects a tag filter, the system shall show only sheets containing that tag.
- [x] SHEETS-CAT-004: While no sheet matches active filters, the system shall present a clear empty-state message.
